# ดูแลผู้สูงอายุ (Elderly Care Assistant) — ต้นแบบ Expo

ต้นแบบแอปจากปริญญานิพนธ์ "แอปพลิเคชันสำหรับผู้ดูแลผู้สูงอายุที่มีโรคประจำตัว"
รันได้ทั้งบน **มือถือ (สแกน QR ด้วย Expo Go)** และ **เว็บ** จากโค้ดชุดเดียวกัน
ไม่ต้องตั้งค่าฐานข้อมูล — ใช้ข้อมูลจำลอง (mock) ในเครื่อง จึงทดสอบได้ทันที

---

## วิธีรันและทดสอบด้วยการสแกน (Expo Go)

ต้องมี Node.js เวอร์ชัน 18 ขึ้นไปก่อน จากนั้น:

```bash
cd elderly-care-app
npm install
npx expo start
```

จะมี **QR code** ขึ้นใน terminal
1. ติดตั้งแอป **Expo Go** ในมือถือ (มีทั้ง iOS App Store และ Google Play)
2. เปิด Expo Go แล้วสแกน QR (iPhone ใช้กล้องสแกนได้เลย)
3. แอปจะโหลดขึ้นมือถือ — มือถือกับคอมต้องอยู่ Wi‑Fi เดียวกัน

> ถ้าสแกนแล้วต่อไม่ติด (เช่นใช้ Wi‑Fi มหาวิทยาลัย) ให้รัน `npx expo start --tunnel` แล้วสแกนใหม่

## วิธีรันบนเว็บ

```bash
npx expo start --web
```

หน้าเว็บจะเปิดที่ `http://localhost:8081` (หรือกด `w` ใน terminal ที่รัน expo อยู่)

## โครงสร้างไฟล์

```
elderly-care-app/
├── App.js                  ตัวจัดการหน้าจอ (router แบบ state)
├── index.js                จุดเริ่มของแอป
├── app.json                ตั้งค่า Expo
├── package.json
└── src/
    ├── theme.js            สี/ขนาดตัวอักษร (เน้นตัวใหญ่ คอนทราสต์สูง)
    ├── data.js             ข้อมูลจำลอง + เกณฑ์สุขภาพ (จากบทที่ 2)
    ├── store.js            เก็บข้อมูล + ฟังก์ชันเพิ่ม/แก้ + การนำทาง
    ├── components/
    │   ├── Screen.js       กรอบหน้า (หัว + แถบล่าง)
    │   └── ui.js           การ์ด ปุ่ม ช่องกรอก ป้ายสถานะ
    └── screens/            หน้าจอทั้งหมด (ตาม ภาพที่ 8-15 ในเอกสาร)
        ├── LoginScreen.js          หน้าสมัคร/เข้าสู่ระบบ
        ├── HomeScreen.js           หน้าหลัก
        ├── PatientInfoScreen.js    หน้าข้อมูลผู้ป่วย
        ├── AddPatientScreen.js     หน้าเพิ่ม/แก้ไขข้อมูลผู้ป่วย
        ├── MedicationScreen.js     หน้าบันทึกการทานยา
        ├── AppointmentScreen.js    หน้านัดหมายพบแพทย์
        ├── ReminderScreen.js       หน้าแจ้งเตือนการทานยา
        ├── HealthScreen.js         หน้าบันทึกค่าสุขภาพ
        ├── GraphScreen.js          หน้ากราฟสุขภาพ
        └── SOSScreen.js            หน้า SOS ฉุกเฉิน
```

## หมายเหตุ

- การเข้าสู่ระบบเป็นแบบจำลอง กดปุ่มใดก็เข้าได้ทันที
- ข้อมูลทั้งหมดอยู่ในหน่วยความจำ ปิดแอปแล้วรีเซ็ตกลับค่าตั้งต้น
- ขั้นพัฒนาเต็มรูปแบบ: ต่อ Supabase ตามดีไซน์ในเอกสาร (9 ตาราง) และเพิ่ม `expo-notifications` สำหรับแจ้งเตือนจริงตามเวลา

ดูรายละเอียดความต่างจากเอกสารได้ที่ไฟล์ `DIFFERENCES.md`
