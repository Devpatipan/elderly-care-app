1.1 ความเป็นมาและความสำคัญของปัญหา 
ประเทศไทยกำลังก้าวเข้าสู่สังคมผู้สูงอายุโดยสมบูรณ์ ส่งผลให้สัดส่วนประชากรผู้สูงอายุ

เพิ่มขึ้นอย่างต่อเนื่อง โดยเฉพาะกลุ่มผู้สูงอายุที่มีโรคประจำตัวหรือโรคเรื้อรัง เช่น โรคความดันโลหิต
สูง โรคเบาหวาน และโรคหัวใจ ซึ่งจำเป็นต้องได้รับการดูแลด้านสุขภาพอย่างใกล้ชิ ดและต่อเนื่อง 
(สำนักงานกองทุนสนับสนุนการสร้างเสริมสุขภาพ, 2565) 

ผู้สูงอายุที่มีโรคประจำตัวจำเป็นต้องได้รับการดูแลในหลายด้าน ไม่ว่าจะเป็นการรับประทาน
ยาอย่างสม่ำเสมอ การติดตามอาการ การปฏิบัติกิจวัตรประจำวัน และการป้องกันภาวะแทรกซ้อน 
หากขาดการดูแลที่เหมาะสม อาจนำไปสู่ปัญหาสุขภาพรุนแรง เช่น โรคหลอดเลือดสมอง โรคหัวใจ 
หรือภาวะไตวายเรื ้อรัง ซึ ่งส่งผลกระทบต่อคุณภาพชีวิตของผู ้สูงอายุโดยตรง (World Health 
Organization, 2021) 

อย่างไรก็ตาม ในทางปฏิบัติ ผู ้ดูแลผู้สูงอายุ ซึ ่งส่วนใหญ่มักเป็นสมาชิกในครอบครัวหรือ
อาสาสมัครในชุมชน อาจประสบปัญหาในการดูแลผู้สูงอายุอย่างมีประสิทธิภาพ เนื่องจากข้อจำกัด
ด้านเวลา ความรู้ทางสุขภาพ หรือภาระหน้าที่อื่น ๆ นอกจากนี้ ผู้สูงอายุจำนวนไม่น้อยยังประสบ
ปัญหาด้านความจำ เช่น การลืมรับประทานยา รับประทานยาผิดเวลา หรือไม่สามารถจดจำข้อมูล
ด้านสุขภาพของตนเองได้อย่างครบถ้วน 

ปัญหาเหล่านี้ไม่เพียงส่งผลต่อสุขภาพของผู้สูงอายุเท่านั้น แต่ยังเพิ่มภาระและความเครียด
ให้แก่ผู้ดูแลอีกด้วย (พัชรี และคณะ, 2564) 

ในปัจจุบัน เทคโนโลยีสารสนเทศและการสื่อสาร โดยเฉพาะแอปพลิเคชันบนสมาร์ตโฟน ได้
เข้ามามีบทบาทสำคัญในการช่วยจัดการข้อมูลและสนับสนุนการดูแลสุขภาพ แอปพลิเคชันสามารถ
ช่วยบันทึกข้อมูลสุขภาพ แจ้งเตือนการรับประทานยา ติดตามอาการ และเป็นช่องทางสื่อสารระหว่าง
ผู้ดูแลกับผู้สูงอายุได้อย่างสะดวกและเป็นระบบ งานวิจัยหลายฉบับพบว่า การใช้แอปพลิเคชันด้าน
สุขภาพสามารถช่วยลดภาระของผู้ดูแล และเพิ่มประสิทธิภาพในการดูแลผู้ป่วยโรคเรื้อรังได้ (Brown 
et al., 2018) 

ดังนั้น ผู้พัฒนาจึงมีแนวคิดในการพัฒนา แอปพลิเคชันเพื่อช่วยเหลือผู้ดูแลผู้สูงอายุที่มีโรค
ประจำตัว เพื่อเป็นเครื่องมือสนับสนุนการดูแลสุขภาพของผู้สูงอายุ โดยแอปพลิเคชัน เพื่อช่วยเหลือ
ผู้ดูแลผู้สูงอายุที่มีโรคประจำตัว จะช่วยให้ผู้ดูแลสามารถติดตามข้อมูลสุขภาพ การรับประทานยา และ
กิจวัตรประจำวันของผู้สูงอายุได้อย่างเป็นระบบ ลดความผิดพลาดในการดูแล และส่งเสริมคุณภาพ

1.4 ขอบเขตด้านความสามารถของระบบ 

ระบบที่พัฒนาขึ้นสำหรับ แอปพลิเคชันสำหรับผู้ดูแลผู้สูงอายุที่มีโรคประจำตัว (Elderly 
Care Assistant Application) มีขอบเขตด้านความสามารถของระบบ ดังนี้ 

1. การจัดการข้อมูลผู้สูงอายุและข้อมูลสุขภาพ 
1.1 ผู้ใช้งานสามารถลงทะเบียนและเข้าสู่ระบบด้วยบัญชีผู้ใช้ส่วนตัว 
1.2 สามารถบันทึกข้อมูลผู้สูงอายุ เช่น ชื่อ–นามสกุล เพศ อายุ โรคประจำตัว  

และประวัติทางการแพทย์เบื้องต้น 
1.3 สามารถบันทึกข้อมูลผู้ป่วยได้หลายคน 
1.4 สามารถบันทึกข้อมูลสุขภาพของผู้สูงอายุในแต่ละวัน เช่น การรับประทานยา 

 
 



4 
 

1.5 สามารถบันทึกค่าทางสุขภาพของผู้สูงอายุ เช่น ความดันโลหิต ระดับน้ำตาลใน 
เลือด อัตราการเต้นของหัวใจ และข้อมูลสุขภาพอ่ืน ๆ ที่เกี่ยวข้อง 

1.6 ผู้ดูแลสามารถเพ่ิม ลบ หรือแก้ไขข้อมูลผู้สูงอายุและข้อมูลสุขภาพที่เก่ียวข้องได้ 
1.7 ระบบสามารถจัดเก็บประวัติข้อมูลสุขภาพย้อนหลัง เพ่ือใช้ในการติดตามและ 

วิเคราะห์ข้อมูลสุขภาพของผู้สูงอายุในระยะยาว 
2. การวิเคราะห์ข้อมูลและการแสดงผลข้อมูลสุขภาพ 

2.1 ระบบสามารถรวบรวมและวิเคราะห์ข้อมูลสุขภาพท่ีบันทึกไว้ เพ่ือนำเสนอผลใน 
รูปแบบกราฟหรือแผนภูมิ เพ่ือให้ผู้ดูแลสามารถติดตามแนวโน้มสุขภาพของผู้สูงอายุได้ 

2.2 สามารถแสดงรายงานสรุปข้อมูลสุขภาพในช่วงเวลาต่าง ๆ เช่น รายสัปดาห์  
หรือรายเดือน เพ่ือช่วยในการติดตามและประเมินสภาวะสุขภาพของผู้สูงอายุ

3.1 ระบบสามารถแจ้งเตือนผู้ดูแลเกี่ยวกับกิจกรรมที่สำคัญในการดูแลผู้สูงอายุ เช่น

1.5 วิธีดำเนินการวิจัย 
 การดำเนินการวิจัยในครั้งนี้ประกอบด้วย การศึกษาเอกสารและงานวิจัยที่เกี ่ยวข้อง การ
วิเคราะห์และออกแบบระบบ การพัฒนาแอปพลิเคชัน และการทดสอบการใช้งานระบบ สำหรับ แอป
พลิเคชันสำหรับผู้ดูแลผู้สูงอายุที่มีโรคประจำตัว (Elderly Care Assistant Application) โดยมี
รายละเอียดขั้นตอนการดำเนินงานวิจัย ดังนี้ 
 1. ศึกษาเอกสาร ตำรา และงานวิจัยที่เกี่ยวข้องกับการดูแลผู้สูงอายุที่มีโรคประจำตัว แนว
ทางการติดตามและดูแลสุขภาพผู้สูงอายุ ตลอดจนเทคโนโลยีที่ใช้ในการพัฒนาแอปพลิเคชันบน
อุปกรณ์เคลื่อนที่ (Mobile Application) รวมทั้งรวบรวมข้อมูลพื้นฐานที่เกี่ยวข้องกับการดูแลสุขภาพ
ผู้สูงอายุ เช่น การรับประทานยา การติดตามอาการ การบันทึกข้อมูลสุขภาพ และการนัดหมายทาง
การแพทย์ เพ่ือนำมาใช้เป็นแนวทางในการพัฒนาระบบ 

2. ดำเนินการวิเคราะห์ความต้องการของผู้ใช้งานระบบ เพ่ือกำหนดขอบเขตและรูปแบบการ
ทำงานของแอปพลิเคชันสำหรับผู้ดูแลผู้สูงอายุที่มีโรคประจำตัว จากนั้นทำการออกแบบโครงสร้าง
และกระบวนการทำงานของระบบ เพื ่อให้สามารถบันทึก ติดตาม และแสดงข้อมูลสุขภาพของ

1.8.3 โรคประจำตัว หมายถึง ภาวะความเจ็บป่วยเรื้อรังของผู้สูงอายุที่ต้องได้รับการดูแลและ 
ติดตามอาการอย่างต่อเนื่อง เพื่อควบคุมสภาวะของโรคไม่ให้เกิดภาวะแทรกซ้อน โดยในงานวิจัยนี้

2.1 แนวคิดเกี่ยวกับ Mobile Application 
คำว่า Mobile Application ประกอบขึ้นด้วยคำสองคำ คือ "Mobile" และ "Application" 

โดย Mobile คืออุปกรณ์สื่อสารที่ใช้ในการพกพา ทำงานได้เหมือนกับเครื่องคอมพิวเตอร์ มีขนาดเล็ก 
น้ำหนักเบา ใช้พลังงานค่อนข้างน้อย ปัจจุบันมักใช้ทำหน้าที่ได้หลายอย่างในการติดต่อแลกเปลี่ยน
ข่าวสารกับคอมพิวเตอร์ ส่วน Application หมายถึงซอฟต์แวร์ที่ใช้เพื่อช่วยการทำงานของผู้ใช้ 
(User) โดย Application จะต้องมีสิ่งที่เรียกว่า ส่วนติดต่อกับผู้ใช้ (User Interface หรือ UI) เพ่ือเป็น
ตัวกลางการใช้งานต่าง ๆ  

Mobile Application คือ โปรแกรมท่ีพัฒนาขึ้นมาเพ่ือใช้งานเฉพาะบนอุปกรณ์เคลื่อนที่ เช่น 
สมาร์ตโฟน แท็บเล็ต โดยมี User Interface หรือส่วนติดต่อผู้ใช้เพ่ืออำนวยความสะดวกในการใช้งาน 

 
 



9 
 

Mobile App จะถูกออกแบบมาเพื่อตอบสนองความต้องการ แก้ปัญหา หรือสร้างความบันเทิงใน
รูปแบบต่าง ๆ แก่ผู้ใช้งาน เช่น แชท เล่นเกม ดูหนัง ฟังเพลง ซื้อสินค้า ชำระเงิน จองบริการ ฯลฯ  

Mobile Application คือ โปรแกรมประยุกต์เพื่อใช้งานบนอุปกรณ์เคลื่อนที่ อาทิ สมาร์ต
โฟน หรือแท็บเล็ต (Tablet) โดย Application หรือที่เราเรียกสั้น ๆ จนติดปากว่า App คือ Software 
ที่ช่วยให้การทำงานของผู้ใช้งาน (User) สะดวกยิ่งขึ้น โดย Application จะต้องมีส่วนติดต่อกับผู้ใช้ 
หรือ User Interface (UI) เพ่ือเป็นตัวกลางในการใช้งาน  

Mobile Application เป็นซอฟต์แวร์ที่พัฒนาขึ้นมาสำหรับใช้งานบนอุปกรณ์ขนาดพกพา ซึ่ง
ปัจจุบันแอปพลิเคชันมือถือได้เข้ามามีบทบาทสำคัญต่อชีวิตประจำวันของทุกคน 

ปัจจุบันโทรศัพท์เคลื่อนที่และแท็บเล็ตได้รับความนิยมเป็นอย่างสูง เนื่องจากมีราคาลดลง
และจำเป็นในการใช้งาน และคาดว่าในอนาคตจะมีการใช้งานกันมากขึ ้นเรื ่อย ๆ ซึ ่งเป็นผลให้
นักพัฒนาแอปพลิเคชันจำเป็นต้องพัฒนาแอปพลิเคชัน เพื่อให้สามารถตอบสนองความต้องการของผู้

คอลัมน์ที่กำหนด แทนการเก็บข้อมูลที่แยกออกจากกัน โดยไม่มีความเชื่อมโยงกัน ซึ่งประกอบด้วย
ข้อมูล (Attribute) ที่มีความสัมพันธ์เชื ่อมโยงกัน (Relation) โดยใช้ RDBMS Tools สำหรับการ
ควบคุมและจัดเก็บฐานข้อมูลที่จำเป็น ทำให้นำไปประยุกต์ใช้งานได้ง่าย ช่วยเพิ่มประสิทธิภาพในการ
ทำงานให้มีความยืดหยุ่นและรวดเร็วได้มากยิ่งขึ้น รวมถึงเชื่อมโยงข้อมูล ที่จัดแบ่งกลุ่มข้อมูลแต่ละ
ประเภทได้ตามต้องการ จึงทำให้ MySQL เป็นโปรแกรมระบบจัดฐานข้อมูลที่ได้รับความนิยมสูง [5] 

MySQL เป็น Open Source ที่ถูกพัฒนาขึ้นจาก MySQL AB ในประเทศสวีเดน  
โดยชาวสวีเดน 2 คน คือ David Axmark และ Allan Larsson ร่วมกับชาวฟินแลนด์ Michael 
Monty Widenius ซึ่งต่อมาในปี ค.ศ. 2008 ถูกซื้อกิจการโดย Sun Microsystems และภายหลัง 
Oracle Corporation ได้เข้าซื้อกิจการในปี ค.ศ. 2010 [5] 

MySQL มีหน้าที่จัดเก็บข้อมูลอย่างเป็นระบบ รองรับคำสั่งภาษา Structured  
Query Language หรือ SQL เพื่อจัดการกับฐานข้อมูลโดยเฉพาะ เป็นภาษามาตรฐานบนระบบ

ซับซ้อน และนิยมใช้งานร่วมกับภาษาโปรแกรม PHP รวมถึงภาษาอื่น ๆ ที่สามารถทำงานร่วมกันกับ
ฐานข้อมูล MySQL ได้หลากหลาย เช่น C, C++, Python, Java เป็นต้น อีกท้ัง MySQL ยังได้รับการ

กับกลไก JavaScript ในตัว นักพัฒนาแอปพลิเคชันเว็บจะเขียนโค้ด JavaScript ที่มีฟังก์ชันที่แตกต่าง

เอนด์ในกรณีนี้ กลไก JavaScript จะอยู่บนเซิร์ฟเวอร์โดยตรง ฟังก์ชัน JavaScript ฝั่งเซิร์ฟเวอร์
สามารถเข้าถึงฐานข้อมูล ดำเนินการทางตรรกะแบบต่าง ๆ และตอบสนองต่อเหตุการณ์ต่าง ๆ ที่ถูก

2.4.6 ฝั่งไคลเอ็นต์เทียบกับฝั่งเซิร์ฟเวอร์ 
 คำว่าไดนามิกอธิบาย JavaScript ทั้งฝั่งไคลเอ็นต์และฝั่งเซิร์ฟเวอร์ พฤติกรรมไดนา 

มิกคือความสามารถท่ีจะอัปเดตการแสดงของเว็บเพจเพ่ือสร้างเนื้อหาใหม่ตามที่จำเป็น ความแตกต่าง
ระหว่าง JavaScript ฝั่งไคลเอ็นต์และฝั่งเซิร์ฟเวอร์อยู่ที่วิธีการที่ JavaScript สร้างเนื้อหาใหม่ โค้ดฝั่ง
เซิร์ฟเวอร์สร้างเนื้อหาใหม่แบบไดนามิกด้วยการใช้ลอจิกของแอปพลิเคชันและปรับเปลี่ยนข้อมูลจาก
ฐานข้อมูล ส่วน JavaScript ฝั่งไคลเอ็นต์สร้างเนื้อหาใหม่แบบไดนามิกภายในเบราว์เซอร์โดยใช้ลอจิก
อินเทอร์เฟซผู้ใช้ และปรับเปลี่ยนเนื้อหาเว็บเพจที่อยู่บนไคลเอ็นต์อยู่แล้ว ความหมายมีความแตกต่าง
กันเล็กน้อยในสองบริบทแต่ก็มีความเกี่ยวข้องกัน และทั้งสองแนวทางทำงานร่ วมกันเพื่อปรับปรุง
ประสิทธิภาพการใช้งานของผู้ใช้ [3] 

  นอกเหนือจากการนำไปใช้ในคุณสมบัติไดนามิกแล้ว ความแตกต่างอีกประการหนึ่ง 
ระหว่างการใช้ JavaScript สองแบบคือทรัพยากรที่โค้ดสามารถเข้าถึงได้ ทางฝั่งไคลเอ็นต์ เบราว์เซอร์
จะควบคุมสภาพแวดล้อมรันไทม์ของ JavaScript โค้ดจึงสามารถเข้าถึงได้เพียงทรัพยากรที่เบราว์เซอร์
อนุญาตให้โค้ดเข้าถึงเท่านั้น ตัวอย่างเช่น โค้ดไม่สามารถเขียนเนื้อหาลงในฮาร์ดดิสก์ของคุณได้เว้นแต่
คุณจะคลิกปุ่มดาวน์โหลด ในทางกลับกัน ฟังก์ชันฝั่งเซิร์ฟเวอร์สามารถเข้าถึงทรัพยากรทั้งหมดของ

2.7  Node.Js 
 2.7.1  NodeJS 

   NodeJS คือ Cross Platform Runtime Environment สำหรับฝั่ง Server เป็น  
Open Source และ Library ที่ใช้สำหรับพัฒนาเว็บแอปพลิเคชันต่าง ๆ ด้วยภาษา JavaScript 
เหมาะสำหรับการสร้างแอปพลิเคชันที่ต้องการใช้ข้อมูลจำนวนมาก และนิยมใช้ในการพัฒนาแอป
พลิเคชันที่ใช้ข้อมูลแบบ Realtime สามารถทำงานได้ทุกระบบปฏิบัติการ โดยถูกนำมาเป็น Web 
Server, IoT, Webkit, TVOS, OS และอ่ืน ๆ เป็นต้น [8] 

2.7.2 NodeJS ทำงานอย่างไร 
    NodeJS ใช้ V8 Engine ที่ถูกพัฒนาโดย The Chromium Project สำหรับเพิ่ม 

ประสิทธิภาพการทำงานของภาษา JavaScript ร่วมกับ Web Browser ให้ดีมากขึ้น โดยการใช้
หลักการ Compile ก่อนประมวลผล (Just-in-time Compilation) ด้วยการเป็นตัวแปลงโค้ดภาษา 
JavaScript หรือ JavaScript Engine ให้เป็น Machine Code ทำให้สามารถทำงานนอก Browser 
อ่ืนได ้เนื่องจากตามปกติแล้ว JavaScript สามารถรันได้บน Client เท่านั้น [8] 

NodeJS ทำงานแบบ Single Process โดยมี Event-loop เข้ามาช่วยในการทำงาน 
แบบAsynchronous คือ รูปแบบการทำงานของชุดคำสั่งที่เขียนขึ้นมา โดยทำงานแบบไม่เรียงขั้นตอน 
เนื่องจากชุดคำสั่งทำงานพร้อมกัน และเมื่อคำสั่งไหนเสร็จเรียบร้อยจะแสดงผลลัพธ์ก่อนแบบ non-
blocking I/O สามารถส่ง Request ของ User 1 และ User 2 พร้อมกันได้เลย ทำให้ลดการใช้ 
Thread ได้ โดย NodeJS ไม่เหมาะสำหรับการทำงานที่เป็น CPU Intensive เพราะทำให้ถูก Block 
การทำงานทั้งหมด [8] 
2.8 โรคเบาหวาน 

2.8.1 ประเภทของโรคเบาหวาน 
เบาหวานแบ่งเป็น 4 ประเภท ดังนี้ 

2.8.1.1 โรคเบาหวานชนิดที่ 1 
พบในเด็กหรือผู้ที่มีอายุน้อยส่วนใหญ่น้อยกว่า 30 ปี มักผอม ตับอ่อน 

ไม่สามารถสร้างอินซูลินได้ ต้องรักษาด้วยการฉีดอินซูลิน ถ้าขาดอินซูลินจะเกิดภาวะหมดสติจาก
น้ำตาลสูงและกรดคีโตนคั่งในเลือด ในประเทศไทยพบผู้เป็นเบาหวานชนิดที่ 1 ร้อยละ 3.4 

2.8.1.2 โรคเบาหวานชนิดที่ 2 
พบมากถึงประมาณร้อยละ 95-97 ของผู้เป็นเบาหวานในประเทศไทย 

เป็นส่วนใหญ่มักอ้วน อายุมากกว่า 40 ปี ตับอ่อนยังพอผลิตอินซูลินได้บ้าง แต่มีภาวะดื้อต่ออินซูลิน 
ในระยะแรกอาจรักษาได้ด้วยการควบคุมอาหารหรือยาเม็ดลดลดระดับน้ำตาล แต่เมื่อเป็นเวลานานๆ 
 
 



16 
 

ในบางรายมีเบต้าเซลล์เสื่อม ทำให้ควบคุมระดับน้ำตาลได้ไม่ดีอาจจำต้องฉีดอินซูลิน 
ปัจจุบันนี้พบในเด็กมากขึ้น โดยเฉพาะเด็กอ้วนเนื่องจากวิถีชีวิตที่ 

เปลี่ยนแปลงไป มีการรับประทานอาหารที่มีไขมันมาก ขาดการออกกำลังกาย มักจะนั่งหน้าจอ
โทรทัศน์หรือจอคอมพิวเตอร์แทนการวิ่งเล่น หรือการเล่นกีฬา 

2.8.1.3 โรคเบาหวานชนิดอื่นที่มีสาเหตุเฉพาะ  
ได้แก่ โรคเบาหวานที่เกิดจากความผิดปกติทางพันธุกรรม โรคของตับอ่อน  

ความผิดปกติของฮอร์โมน การได้รับยาบางชนิด เช่น ยากลุ่มสเตียรอยด์ หรือสารเคมี เป็นต้น 
2.8.1.4 โรคเบาหวานที่เกิดขึ้นขณะตั้งครรภ์  

โรคเบาหวานชนิดนี้ผู้เป็นจะต้องไม่มีประวัติเป็นโรคเบาหวานมาก่อน 
ตั้งครรภ์ ในช่วงระหว่างการตั้งครรภ์จะมีฮอร์โมนจากรกซึ่งมีฤทธิ์ต้านอินซูลินเป็นผลให้ร่างกาย
ตอบสนองต่ออินซูลินลดลง ถ้าไม่สามารถเพ่ิมการสร้างอินซูลินให้เพียงพอ 

2.8.2 สาเหตุของการเกิดโรคเบาหวาน 
โรคเบาหวาน (Diabetes) คือโรคที่เกิดจากความผิดปกติของการทำงานของฮอร์โมน 

ที่ชื่อว่า อินสุลิน (Insulin) ซึ่งโดยปกติแล้วร่างกายของคนเราจำเป็นต้องมีอินสุลิน เพื่อนำน้ำตาลใน
กระแสเลือดไปเลี้ยงอวัยวะต่าง ๆ ของร่างกาย โดยเฉพาะสมองและกล้ามเนื้อ ในภาวะที่อินสุลินมีค
วามผิดปกติ ไม่ว่าจะเป็นการลดลงของปริมาณอินสุลินในร่างกาย หรือการที่อวัยวะต่าง ๆ ของ
ร่างกายตอบสนองต่ออินสุลินลดลง (หรือที่เรียกว่า ภาวะดื้ออินสุลิน) จะทำให้ร่างกายไม่สามารถนำ
น้ำตาลที่อยู่ในกระแสเลือดไปใช้ได้อย่างเต็มประสิทธิภาพ ทำให้มีปริมาณน้ำตาลคงเหลือในกระแส
เลือดมากกว่าปกต ิ

สาเหตุของโรคเบาหวานเกิดจากการที่ระดับน้ำตาลในกระแสเลือดสูงมากข้ึนถึง 
ระดับหนึ่ง จนทำให้ไตดูดกลับน้ำตาลได้ไม่หมด ซึ่งปกติไตจะมีหน้าที่ดูดกลับน้ำตาลจากสารที่ถูกกรอง
จากหน่วยไตไปใช้ ส่งผลให้มีน้ำตาลรั่วออกมากับปัสสาวะ จึงเป็นที่มาของคำว่า “โรคเบาหวาน” หาก
เราปล่อยให้เกิดภาวะเช่นนี้ไปนาน ๆ โดยไม่ได้รับการรักษาอย่างถูกวิธี จะทำให้เกิดภาวะแทรกซ้อนที่
ร้ายแรงตามมาในที่สุด [1] 

2.8.3 อาการของโรคเบาหวาน 
  ผู้ป่วยเบาหวานในระยะแรกที่ระดับน้ำตาลในเลือดยังไม่สูงมาก อาการจะยังไม่
เด่นชัด อย่างไรก็ตามอาจไปพบแพทย์ด้วยอาการต่าง ๆ ดังนี้ 

 2.8.3.1 อาการระดับน้ำตาลในเลือดสูง ได้แก่ รับประทานเก่งขึ้น หิวน้ำบ่อย 
ปัสสาวะบ่อยอ่อนเพลีย ถ้าระดับน้ำตาลสูงนาน ๆ และยังไม่ได้รับการรักษาจะมีน้ำหลังตัวลดลง
ตามมา 

2.8.3.2 อาการของภาวะแทรกซ้อนเรื้อรัง เช่น ตามัว ไตวาย ชาปลายมือปลายเท้า

2.8.3.3 อาการของน้ำตาลสูงเฉียบพลัน เช่น อ่อนเพลียมาก คลื่นไส้อาเจียน หายใจ

2.8.3.4 อาการหรือโรคที่สัมพันธ์กับโรคเบาหวาน เช่น แผลเรื่อรังหรือแผลหายช้า

2.8.4  ระดับค่าน้ำตาลในเลือด 
 ระดับน้ำตาลในเลือด  คือการวัดระดับความเข้มข้นของน้ำตาลในเลือดเพ่ือประเมิน 

ว่าร่างกายสามารถควบคุมน้ำตาลได้ดีมากน้อยเพียงไร การตรวจวัดระดับน้ำตาลในเลือด หรือการ
เจาะน้ำตาลหลังอดอาหารและเครื่องดื่มทุกชนิดมาแล้วอย่างน้อย 8 ชั่วโมง (Fasting Blood Sugar: 
FBS) โดยระดับน้ำตาลในเลือดจะสามารถบ่งบอกถึงปริมาณของกลูโคสในกระแสเลือด ณ ขณะนั้นว่า
อยู่ในระดับใด ซึ่งการตรวจน้ำตาลในเลือดนี้เป็นการตรวจที่ช่วยคัดกรองและวินิจฉัยว่าเรามีเสี่ยงเป็น
เบาหวานหรือไม่ 

ปัจจุบันเราสามารถตรวจวัดระดับน้ำตาลในเลือดได้ด้วยตนเอง (Self-Monitoring  
of Blood Glucose) ซึ่งสามารถตรวจได้เองเป็นประจำ มีข้อดีคือ ทำให้ทราบความเสี่ยงว่าเป็น
เบาหวานหรือไม่ และทำให้ผู้ที่เป็นโรคเบาหวานสามารถปรับพฤติกรรมการดูแลตนเองได้ทันที 

ระดับน้ำตาลในเลือด 
2.8.4.1 ระดับน้ำตาลในเลือด อยู่ระหว่าง 70-100 อยู่ในภาวะปกติ 
2.8.4.2 ระดับน้ำตาลในเลือดเท่ากับ 100 – 125 มีภาวะความเสี่ยง หรือเรียกว่า  

เบาหวาน 
2.8.4.3 ระดับน้ำตาลในเลือด มากกว่า 126 มีความเสี่ยงเป็นโรคเบาหวาน 
ภาวะที่ร่างกายมีระดับน้ำตาลกลูโคสในเลือดสูงกว่าปกติ ซึ่งระดับน้ำตาลที่ปกติจะ 

อยู่ที่ประมาณ 70-100 มิลลิกรัมต่อเดซิลิตร แต่หากค่าที่ได้สูงกว่า 100 มิลลิกรัมต่อเดซิลิตร ขึ้นไป
อาจเสี่ยงต่อการเป็นโรคเบาหวาน [1]

2.10.2.7 เหงื่อออกมากผิดปกติ คลื่นไส้ หรืออาเจียน โดยเฉพาะในผู้ที่มีภาวะหัวใจ

2.11 งานวิจัยท่ีเกี่ยวข้อง 

ศุภรัตน์ แก้วเสริม (2565) ได้พัฒนาแอปพลิเคชันบนสมาร์ทโฟนสำหรับการดูแลผู้สูงอายุ 
โดยใช้กระบวนการพัฒนาระบบตามวงจร SDLC (System Development Life Cycle) 
แอปพลิเคชันประกอบด้วย 3 ฟังก์ชันหลัก ได้แก่ (1) การให้คำปรึกษาทางการแพทย์ผ่านระบบแช็ต 
(2) การเรียกใช้หน่วยแพทย์ฉุกเฉินพร้อมระบบระบุตำแหน่ง GPS และ (3) การให้ความรู้ด้านสุขภาพ
ในรูปแบบบทความ ผลการประเมินความพึงพอใจจากกลุ่มตัวอย่าง 174 คน พบว่า มีความพึงพอใจใน
ภาพรวมอยู่ในระดับมากที่สุด (x ̄ = 4.46, S.D. = 0.57) สะท้อนให้เห็นว่าแอปพลิเคชันสามารถ
ตอบสนองความต้องการของผู้ใช้งานได้อย่างมีประสิทธิภาพ [12] 

มานิตา เจือบุญ และคณะ (2564) งานนี้มุ ่งพัฒนาเครื่องมือดิจิทัลสำหรับประเมินภาวะ
โภชนาการและให้คำแนะนำการบริโภคที่เหมาะสมกับผู้สูงอายุ เพื่อสนับสนุนการดูแลโภชนาการ
รายบุคคล. เป้าหมายเน้นทั้งการประเมินสถานะโภชนาการและการเสนอแนวทางปฏิบัติที่ผู้สูงอายุ
สามารถนำไปใช้ได้จริง พัฒนาโมบายแอปพลิเคชันเพื่อประเมินภาวะโภชนาการและเสนอแนวทางการ
บริโภคสำหรับผู้สูงอายุ วิจัยออกแบบและพัฒนาแอปพลิเคชันบนแพลตฟอร์มมือถือซึ่งรวมแบบ
ประเมินภาวะโภชนาการและคำแนะนำด้านอาหารแก่ผู้สูงอายุ. ผลการประเมินจากแอปถูกนำเสนอใน
รูปแบบที่สามารถนำไปปฏิบัติได้จริงโดยผู้ใช้หรือผู้ดูแล [11] 

พัสตราภรณ์ ทิพยโสธร และคณะ ได้ทำการวิจัยเกี่ยวกับสถานการณ์สุขภาพของผู้สูงอายุและ
ปัญหาการเดินทางของผู้สูงอายุในพื้นที่รอบเมืองกรุงเทพมหานคร เพื่อทำความเข้าใจปัจจัยที่มีผลต่อ
การเดินทางไปรับบริการสุขภาพของผู้สูงอายุ โดยผลการวิจัยได้เสนอแนะแนวทางในการพัฒนาระบบ
ต่าง ๆ ที่เกี่ยวข้อง เพ่ือช่วยให้ผู้สูงอายุสามารถเข้าถึงบริการสุขภาพได้สะดวกมากยิ่งขึ้น การวิจัยครั้งนี้
ใช้ระเบียบวิธีวิจัยทั้งเชิงปริมาณและเชิงคุณภาพ โดยมีการเก็บรวบรวมข้อมูล 3 ขั้นตอน ได้แก่ การ
สำรวจด้วยแบบสอบถามเพื ่อเก็บข้อมูลเกี ่ยวกับการเดินทางของผู ้สู งอายุจำนวน 407 คน การ
สัมภาษณ์เชิงลึกผู้สูงอายุจำนวน 154 คนจากกลุ่มตัวอย่างเดิม โดยใช้แผนที่ประกอบการสัมภาษณ์
เพื่อทำความเข้าใจลักษณะและเส้นทางการเดินทาง และการสำรวจสังเกตการณ์โดยการร่วมเดินทาง
จริงกับผู้สูงอายุ เพื่อสังเกตและศึกษาปัจจัยต่าง ๆ ที่มีผลต่อการเดินทาง ผลการวิจัยพบว่า กิจกรรม
ด้านสุขภาพเป็นเหตุผลสำคัญหลักที่ทำให้ผู้สูงอายุเดินทางไปยังโรงพยาบาล โดยผู้สูงอายุส่วนใหญ่มัก
มีญาติร่วมเดินทางและมีความคุ้นเคยกับเส้นทาง จึงทำให้ใช้เวลาในการเดินทางไม่นาน นอกจากนี้ 
การได้รับข้อมูลเกี่ยวกับสุขภาพยังเป็นปัจจัยสำคัญที่ส่งผลต่อการตัดสินใจเดินทางไปรับบริการสุขภาพ
ของผู้สูงอายุ ซึ่งผู้สูงอายุมักได้รับข้อมูลด้วยตนเองหรือผ่านผู้ดูแล เช่น ญาติหรือบุตรหลาน อีกทั้ง
ผู้สูงอายุในแต่ละกลุ่มยังใช้เวลาในการเตรียมตัวก่อนการเดินทางแตกต่างกันไป จากการศึกษาปัจจัย
ต่าง ๆ ที่เกี่ยวข้องกับการเดินทางของผู้สูงอายุในครั้งนี้ จึงสามารถนำผลการวิจัยไปใช้เป็นแนวทางใน

และความดันโลหิตของผู้รับบริการเพื่อนำมาจำแนกกลุ่มที่มีภาวะเสี่ยง จากนั้นมีการบันทึกค่าไว้ให้เห็น
แนวโน้มผลการคัดกรองในแต่ละครั้ง กรณีท่ีระดับน้ำตาลในเลือด และ ความดันโลหิตมีค่าเกินหรือต่ำ
กว่ามาตรฐาน ผู้ป่วย ผู้สูงอายุ และคนในครอบครัวจะทราบถึงความผิดปกติของ อาการเจ็บป่วยทันที 
สามารถหาวิธีการป้องกัน วิธีการรักษา และเฝ้าระวังพฤติกรรมการรับประทานอาหาร การออกกำลัง

บริการสาธารณสุขนำไปใช้ในการป้องกันโรคในกลุ่มประชาชนทั่วไป กลุ่มป่วย และกลุ่มเสี่ยง ช่วยให้

 3.4.4 ออกแบบหน้าแอปพลิเคชั่น 
 3.5.4.1 การออกแบบ Data Flow Diagram (DFD)  
  การออกแบบแผนภาพกระแสข้อมูล (Data Flow Diagram: DFD) เป็น
กระบวนการสำคัญในการวิเคราะห์และออกแบบโครงสร้างทางเทคนิคของแอปพลิเคชันสำหรับผู้ดูแล
ผู้สูงอายุที่มีโรคประจำตัว เพ่ือให้เห็นภาพรวมของการรับส่งข้อมูลภายในระบบอย่างเป็นลำดับขั้นตอน 
ตั้งแต่การจัดเก็บข้อมูลสุขภาพพื้นฐานไปจนถึงกระบวนการประมวลผลเพื่อช่วยในการตั ดสินใจของ
ผู้ดูแล โดยในส่วนของแผนภาพบริบท (Context Diagram หรือ DFD ระดับ 0) ระบบถูกออกแบบให้
มีปฏิสัมพันธ์หลักกับกลุ่มบุคคล 3 กลุ่ม คือ ผู้สูงอายุ/ผู้รับการดูแล  ผู้ดูแล/ญาติ และ ผู้ดูแลระบบ ซึ่ง
มีการไหลของข้อมูลที่เป็นระบบและเอื้อต่อการดูแลเชิงรุก โดยผู้ ดูแลผู้สูงอายุสามารถป้อนข้อมูล
สุขภาพประจำวัน เช่น ค่าความดันโลหิต ระดับน้ำตาลในเลือดหรือแม้แต่การส่งสัญญาณแจ้งเหตุ
ฉุกเฉิน (SOS) เข้าสู่ระบบ ในขณะที่ระบบจะทำการประมวลผลและวิเคราะห์ข้อมูลเหล่านั้นเพื่อส่ง
ผลลัพธ์กลับไปยังผู้สูงอายุในรูปแบบของคำแนะนำในการปฏิบัติตัวและการแจ้งเตือนกิจวัตรสำคัญ 
และในขณะเดียวกัน ระบบจะทำหน้าที่เชื่อมโยงข้อมูลสำคัญไปยังผู้ดูแลโดยตรง เพ่ือให้ผู้ดูแลสามารถ
ตรวจสอบสถานะสุขภาพแบบเรียลไทม์ ติดตามแนวโน้มความเสี่ยงของโรค และรับการแจ้งเตือนทันที
เมื่อเกิดเหตุการณ์ผิดปกติ ซึ่งช่วยให้การบริหารจัดการข้อมูลสุขภาพของผู้สูงอายุมีความแม่นยำ 
ปลอดภัย และลดความกังวลให้แก่ผู้ดูแลได้อย่างมีประสิทธิภาพ
